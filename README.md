# 🃏 Cartifact 개발 프로젝트

Unity 6 기반으로 제작 중인 **로그라이크 덱빌딩 및 턴제 카드 전투 게임** 프로젝트입니다.  
단순한 기능 구현을 넘어 **유지보수 가능한 구조, 확장 가능한 시스템, 데이터 중심 설계**를 목표로 지속적인 리팩토링을 진행하고 있습니다.

---

## 🎮 게임 루프 및 소개

플레이어는 스테이지마다 무작위로 주어지는 카드를 선택하여 자신만의 덱을 구성하고, 턴제 전투를 통해 적을 격파해 나갑니다.

## 🛠️ 핵심 시스템

### 1. 턴제 전투 시스템 (Turn-Based Battle)
* **코루틴(Coroutine) 기반 연출 제어**: 플레이어와 적의 공격 턴, 대사 출력 타이밍, HP 바 감소 등의 UI 연출 프로세스를 순차적으로 동기화하여 자연스러운 전투 흐름을 구현했습니다.
* **텍스트 타자기 연출**: 텍스트를 한 글자씩 출력하는 연출을 구현하여 전투 상황의 가시성과 몰입도를 높였습니다.

### 2. 로그라이크 난이도 스케일업 (Scale-Up System)
* **싱글톤(Singleton) 데이터 관리**: 씬(Scene) 전환 시에도 데이터가 유지되는 `GameManager`를 통해 현재 판 수(`GameTurnCount`)를 누적 관리합니다.
* **동적 적 스펙 강화**: 판 수가 상승할 때마다 적의 최대 체력과 무작위 공격력 범위가 자동으로 스케일업되는 난이도 곡선 공식을 적용했습니다.

### 3. 데이터 중심 설계 & 자동화
* **ScriptableObject 기반 데이터 관리**: 카드의 고유 효과 및 능력치를 `CardData`를 통해 데이터 중심으로 분리하여 기획 변경에 유연하게 대처할 수 있습니다.
* **레이캐스트(Raycast 2D) 기반 매니저 자동 참조**: 마우스 클릭 및 터치 인터페이스 구현 시, 인스펙터 드래그 방식 대신 런타임에 오브젝트 이름으로 컴포넌트를 자동 탐색(`GameObject.Find`)하여 개발 효율성을 높였습니다.

## 🚀 개발 목표

* **유지보수성 극대화**: 스크립트 간의 결합도를 낮추고 데이터와 로직을 명확히 분리합니다.
* **유연한 확장성**: 향후 새로운 카드 효과나 특수한 패턴을 가진 AI 적이 추가되어도 기존 코드를 손대지 않고 확장할 수 있는 구조를 지향합니다.

## 🏃‍♂️ 실행 방법

1. **Unity 6** 버전으로 프로젝트를 엽니다.
2. `File -> Build Profiles` (또는 `Build Settings`) 창을 열어 `TitleScene`, `MainGame`, `BattleScene` 등 필요한 씬들이 빌드 목록에 정상적으로 등록되어 있는지 확인합니다.
3. **Title Scene**을 연 뒤, 에디터 상단의 **Play(▶️)** 버튼을 클릭합니다.
4. 화면을 클릭하여 메인 게임으로 진입합니다.
